时间助手 · Support

使用指南、常见问题与开发者联系方式。

1. 功能一览

时间助手主要提供以下能力：

  • 时间轴视图：按日、周、月、年查看所有活动记录。
  • 标签管理：自定义 #工作 #学习 #运动 等标签，对记录进行分类与筛选。
  • 计时器：一键开始追踪当前活动，支持预设活动模板。
  • 数据分析：日 / 周 / 月 / 年维度的环形图与时间分配列表。
  • 血压 OCR：对准血压计拍照，自动识别收缩压、舒张压、脉搏。
  • 体重记录：结构化模板录入，快速记录体重与备注。
  • PDF 导出：将记录导出为 PDF 文档，方便分享与归档。
  • iCloud 同步：基于 CloudKit 跨设备同步你的记录与标签。
  • 语音 & Siri：支持系统听写输入与 Siri 快捷指令。

2. 快速上手

2.1 创建第一条记录

  1. 打开 App，默认进入「时间轴」标签。
  2. 点击右上角「+」按钮，选择时间段或时间点记录方式。
  3. 填写开始 / 结束时间，活动名称，以及可选的标签。
  4. 点击「创建记录」即可在时间轴上看到。

2.2 使用计时器

  1. 切到「计时器」标签。
  2. 选择预设活动，或在「自定义」中输入新活动名称与标签。
  3. 点击「开始」按钮，计时器开始运行。
  4. 完成后点击「停止」，将自动生成一条时间段记录。

2.3 血压 OCR

  1. 在「时间轴」中点击「+」按钮并选择「血压」模板。
  2. 点击相机图标，对准血压计屏幕拍照。
  3. App 会在设备本地完成识别，自动填充高压 / 低压 / 脉搏。
  4. 核对数据后保存即可。

2.4 开启 iCloud 同步

  1. 进入「设置」标签页。
  2. 打开「iCloud 同步」开关（首次开启会消耗一次高级功能免费额度，或需要解锁高级会员）。
  3. 等待几秒，同步状态指示点变绿后即完成。

3. 高级会员

免费用户拥有 30 次高级功能使用额度，超出后可以选择购买高级会员解锁：

  • iCloud 同步：跨设备自动同步。
  • OCR 识别：无限次血压 OCR 识别。
  • 数据导出：无限制 PDF 导出。

进入「设置 → 高级会员」可查看剩余免费次数、购买或恢复购买。

4. 常见问题

Q：时间助手会收集我的数据吗？

A：不会。所有记录默认存储在本地，只有开启 iCloud 同步后才会进入你自己的 Apple ID 私有 CloudKit 数据库，开发者无法读取。

Q：为什么需要相机 / 相册权限？

A：用于血压 OCR 识别血压计屏幕。仅在主动使用 OCR 功能时申请，图片在设备本地处理，不会上传。

Q：为什么需要麦克风 / 语音识别权限？

A：用于系统听写输入，让你以语音方式快速创建记录。音频流由系统处理，应用不直接存储。

Q：开启 iCloud 同步后如何关闭？

A：在「设置 → iCloud 同步」中关闭即可。关闭后本地数据保留，已同步数据由你在 iCloud 设置中自行管理。

Q：免费试用次数用完会怎样？

A：高级功能（iCloud 同步、OCR、PDF 导出）会被锁定，基础的时间记录、标签、计时器、数据分析功能不受影响。

Q：怎么导出我的数据？

A：在记录详情页或设置中选择「导出 PDF」，可生成包含所选时间范围内所有记录的 PDF 文件。

Q：可以删除单条记录或全部数据吗？

A：可以。在「记录详情」页点击「删除」可删除单条；卸载 App 即可清空本地全部数据。

Q：支持 macOS 吗？

A：支持。时间助手同时提供 iOS 与 macOS 版本，macOS 版还提供菜单栏快捷入口。
